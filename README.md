# 손목터널증후군
 
<img width="1026" height="791" alt="Ddang_G" src="https://github.com/user-attachments/assets/e6a0e5fa-68b0-4f4e-8a17-2e5b2407db69" />

기본적인 박자 연습을 위한 메트로놈입니다.

## 실행

`손목터널증후군.exe` 또는 `Start.cmd`를 더블 클릭하면 독립된 Windows 창이 열립니다. 브라우저나 인터넷 연결이 필요하지 않습니다. Windows의 .NET Framework 4.x를 사용합니다.

사용자 요청으로 소스 코드와 빌드 스크립트는 삭제했습니다. 실행 파일 또는 Start.cmd로 실행하세요.

## 기능

- BPM 30~240: 숫자 입력, 슬라이더, + / − 버튼으로 조절
- 한 마디 박자 수 1~16 선택 (기본 4박자)
- 음표 선택: 4분음표, 8분음표, 셋잇단음표, 16분음표
- 박자 번호 표시: 선택한 수만큼 세고 첫 박자부터 반복
- 첫 박자 강조 켜기/끄기
- 볼륨 조절, 시작/정지, 시각적인 박자 표시
- 단축키: Space 시작/정지, 위/아래 방향키 BPM 조절

한 박은 4분음표 기준입니다. BPM 60에서 4분음표는 1초에 1번, 8분음표는 2번, 셋잇단음표는 3번, 16분음표는 4번 클릭합니다. 박자 수는 한 마디 길이를 정하며 음표 설정과 별개입니다. 첫 박자 강조는 마디 첫 클릭에만 적용됩니다. 음표 또는 박자 수 변경 시 마디 처음부터 다시 시작합니다. 선택창에 포커스가 있으면 방향키로 항목을 선택합니다.

## 구현 및 제한

기본 실행 버전은 C# Windows Forms GUI입니다. 별도 작업 스레드에서 Stopwatch 시계로 박자를 계산하고 생성한 WAV 클릭음을 SoundPlayer로 재생합니다. 박자 수를 바꾸면 첫 박자부터 다시 시작합니다. 볼륨 변경 순간에는 재생 중인 클릭음이 짧게 끊길 수 있습니다.

Windows 스케줄링과 오디오 장치에 따른 지연이 있으므로 전문 오디오 장비 수준의 정밀도를 보장하지 않습니다. 절전에서 돌아올 때 놓친 박자를 한꺼번에 재생하지 않습니다.

## 파일

- `Metronome.cs`: Windows GUI 및 오디오
- `Build.ps1`: 실행 파일 빌드
- `Start.cmd`: Windows GUI 실행
- `프로젝트기록.md`: 결정 사항 및 수정 이력

## 자동 템포 및 소리
- 자동 변경: 1~999마디마다 + 증가 / − 감소 방향과 0~210 BPM 변화량을 별도로 선택합니다. 예: 4마디, +5이면 4마디 완료 후 다음 마디 첫 박부터 5 BPM 증가. 0은 유지.
- BPM은 30~240 범위. 정지 시 현재 BPM 유지. 재시작, 박자/음표/자동 변경 설정 변경 시 마디 계산 초기화.
- 소리: 기본 클릭, 우드블록, 전자 비프, 하이햇. 볼륨 및 첫 박자 강조 적용. 작은 화면에서는 스크롤하여 조작.

## 커스텀 MP3 클릭 소리

- 프로그램 옆 `Mso` 폴더에 MP3를 넣으면 1.5초 이내에 클릭 소리 목록에 `커스텀 · 파일명`으로 나타납니다. 새로고침 버튼으로 즉시 갱신할 수도 있습니다.
- GUI의 `커스텀 소리 넣기`로 MP3를 여러 개 선택하면 Mso에 복사하고 마지막으로 추가한 소리를 선택합니다. 같은 이름은 숫자를 붙여 보관합니다.
- 목록에서 커스텀 소리를 선택하면 각 클릭 때 파일 처음부터 재생합니다. 긴 소리는 다음 클릭에 의해 잘릴 수 있으므로 앞부분에 무음이 없는 짧은 음원이 좋습니다.
- Windows Media Foundation으로 MP3를 한 번 변환하고 메모리의 WAV를 재생합니다. 별도 플레이어 설치가 필요하지 않습니다. 변환 후 64MB 이하의 파일을 지원합니다.
- 볼륨과 첫 박자 강조가 커스텀 소리에도 적용됩니다. 첫 박자 강조는 볼륨을 높이는 방식이며, 최대 볼륨에서는 차이가 줄어듭니다.
- 파일을 추가한 뒤 프로그램을 재실행해도 Mso의 파일을 다시 표시합니다.

## 화면 구성
가로 450px, 기본 내용 높이 750px의 화면입니다. 박자/소리/BPM 자동 변경 탭에서 설정합니다. BPM, 박자 표시, 시작/정지와 진행 상태는 탭에 관계없이 보입니다. 화면 높이가 부족할 때만 스크롤합니다.
